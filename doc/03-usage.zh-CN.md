# 使用

[English](03-usage.md) · 简体中文

日常怎么用：按键、手势、批准、听写、侧放的页面、席位和设置页。屏幕在什么时候显示哪一页的完整规则见[屏幕规则](06-screen-rules.zh-CN.md)。

## 按键

屏幕朝向你、三个键在上方时：

| 键 | 短按 | 长按 |
|---|---|---|
| 左键（BOOT） | 静音 / 取消静音 | 1 秒：钉住或解除钉住当前页 |
| 中键（PWR） | 开机；开着时显示名牌和状态灯 | 3 秒：关机 |
| 右键 | | 按住说话（听写） |

中键只能短按，不能做成按住说话的键：按得够久，硬件一定会断电。

## 脸页上的手势

| 手势 | 作用 |
|---|---|
| 左右滑 | 切到下一个 / 上一个席位 |
| 上下滑 | 音量加 / 减 |
| 点一下 | 显示席位名牌和状态灯 3 秒 |
| 双击 | 档案卡（等级和经验），再点关闭 |
| 长按 1.5 秒 | 设置卡：皮肤、亮度、链路和电量 |
| 来回搓脸 | 摸头：呼噜、脸红 |
| 摇晃 | 晕了 |

## 批准

agent 要你确认时，它的状态变成**等你批准**。不管板子正显示什么，都会跳到那个 agent 的脸并浮出「✓ 批准」。

- **点一下** = 批准，**长按 0.7 秒** = 拒绝。
- host 先把那个 agent 的窗口拉到前台，再替你按键（默认回车 / Esc，可以在设置页按席位改）。
- 答完后板子回到原来那一页。

## 同时开几个 Claude Code 窗口

Claude Code 终端开几个都行，Claude 席位还是一张脸。开了两个以上时，脸的顶部会和底部状态行一起浮出一行（点一下屏幕时，以及正显示的会话在等你批准时）：这个会话的题目，也就是 Claude 写在终端标签页上的那几个字（没有题目就显示文件夹名），后面跟着它排第几，比如 `2/4`。

- **点顶部这条的左半** = 上一个会话，**右半** = 下一个，两头循环。
- 脸、「✓ 批准」气泡和听写都跟着顶部这个会话走：板上看到哪个会话，就操作哪个会话。停手 1.5 秒后，Mac 把那个会话的标签页拉到前台。
- 别的会话来权限询问，这一行会立刻跳过去，它的标签页也到前台。几个会话同时在等，按提问先后一个个答；后面还有会话排队时，计数变绿。
- 在 Mac 上往哪个会话里打字，这一行就跟到哪个。
- 能精确跳到标签页的终端：Warp、系统自带的终端；iTerm2 和 Ghostty 已支持但还没实测。终端、iTerm2、Ghostty 第一次会问是否允许 `AgentPetHost` 控制它们。其他终端（VS Code、Cursor 等）只能把 app 拉到前台，所以两个会话开在同一个这样的 app 里时，板子会提示「请在 Mac 上批准」，不去猜是哪个标签页。
- 装上或升级 AgentTouch 之前就开着的会话，按文件夹也能认出来，不用重开。

## 听写

按住右键说话。松开后浮出「⏎ 发送」6 秒，点一下屏幕就是回车。

- 在脸页说，字进当前席位的 app；在其他页说，字落在 Mac 此刻的光标处。
- Mac 端是替你按住 fn 键，所以需要一个按住 fn 就能语音输入的输入法（作者用微信输入法）。
- 默认用 Mac 的麦克风。想对着板子说，在设置页「语音听写 → 声音从哪来」选板子（需要装 BlackHole 虚拟声卡）。

## 侧着放

三个键朝上立着放，是脸页；换一条侧边朝下立着，它就变成别的东西；屏幕朝上平放时，停在原来那一页。

| 摆法 | 页面 | 手势 |
|---|---|---|
| 左侧边朝下（SD 卡槽那边） | 圆环钟表 | 左滑：Mac 正在播放 · 右滑：卡上的播客 |
| 右侧边朝下（喇叭那边） | 黄历 ⇄ 日历 | 左右滑：互换 · 黄历页上下滑换一签，点一下念给你听 |
| 扣在桌上 | 睡觉（静音） | 翻回来或拿起来就醒 |

正在播放和播客页卡片下方的三个区域是 上一首 / 播放暂停 / 下一首（播客页是 ±15 秒）。播客在设置页「听什么」里添加。

## 钉住

长按左键 1 秒，**钉住**屏上这一组页面：转动或拿起板子都不再换页，只把画面转正。再长按一次解除。脸页上也可以点右下角的图钉。等你批准的请求照样会抢屏。

## 席位

板子有五个席位，一个 agent 一个：

| 席位 | agent | 拉到前台的 app |
|---|---|---|
| `claude` | Claude Code | 你的终端（默认 Warp） |
| `codex` | Codex | ChatGPT |
| `qoder` | Qoder IDE | Qoder IDE |
| `qoderwork` | 千问办公 | 千问办公 |
| `forest` | Qoder 桌面版 | Qoder |

- app 没开的席位会隐藏，滑动时跳过（在设置页打开「显示离线席位」可以一直显示五个）。
- 在板上切席位，停手 1.5 秒后 Mac 把那个 app 拉到前台，光标放进输入框。反过来，在 Mac 上点进某个 agent 的 app，板子也跟过去。
- 设置页「席位」一节：「扫描本机」找出你装了哪些 agent；每个席位选拉起哪个 app、批准键 / 拒绝键、穿哪套皮肤。「交给我的 agent」会复制一句话，让你的编程 agent 替你配。

## 皮肤

六套皮肤：classic、kitty、robo、bunny、sprout、grok。每个席位穿一套，两个席位不会穿同一套：点了别人正穿着的，两家互换。在板上（长按脸 → 设置卡）或设置页里都能换。

## 设置页

<http://127.0.0.1:8788/settings>。侧栏顶部切换 中文 / English，板子跟着切（黄历页特意保留中文）。

| 一节 | 内容 |
|---|---|
| 总览 | 板子、卡上字库、host 和各席位此刻的状态，每 2 秒刷新 |
| 板子 | 板子跟着哪台 Mac、它的 Wi-Fi |
| 席位 | 本机的 agent，每个席位的 app / 按键 / 皮肤 |
| 声音 | 音量；等你批准和干完活时叫一声还是说话 |
| 语音听写 | 用哪个麦克风、走哪条链路 |
| 拿起时显示 | 拿起板子时显示哪一页 |
| 行为 | 跟随 Mac 前台 app、休息提醒、离线席位 |
| 正在播放 | 显示 Mac 正在播放的内容 |
| 听什么 | 往卡上放播客和音频 |
| host | 重启、内存趋势、日志、调试按钮 |

## 宠物的一面

- 插电它会吃饭，充满了打个嗝。
- 冷落它 10 分钟会叹气求关注，戳它一下就开心了。
- 连续干活 90 分钟，它会喊你休息。
- 档案卡上的等级随干完的活、摸头次数和相处天数增长。

## 电池与电源

- 设置卡上显示电量，充电时带 `CHG`，充满显示 `FULL`。
- 用电池时，电量第一次降到 20% 以下，不管在哪一页都会弹出「电量低 · N%」4 秒，降到 10% 以下再弹一次；一直低着就每 10 分钟再弹一次（10% 以下每 5 分钟）。电量低期间屏上还常驻一个小电池图标：脸页在右上角，其他页在左下角。
- 电量低于 10% 每 3 分钟叹一次气；到 5% 自动关机。
- 3 分钟找不到认识的 Wi-Fi，它会关掉 Wi-Fi 省电。蓝牙照常，只有语音播报需要 Wi-Fi。

## 配置文件

大多数设置存在 `~/.agentpet/config.json`，设置页会替你写。几个可能想手动改的：

```json
{
  "approve_keys": {"codex": "cmd+enter"},
  "follow_front": false,
  "stretch_after_min": 0,
  "pickup_page": "follow"
}
```

`stretch_after_min: 0` 关掉休息提醒。手动改完要 `pet restart` 重启 host。
