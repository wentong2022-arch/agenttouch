# 屏幕规则

[English](06-screen-rules.md) · 简体中文

这一页只回答一个问题：任意时刻，屏幕该显示哪一页？内容以固件（`firmware/src/main.cpp`）的实际行为为准。

## 屏幕主权

**needs_you 是唯一有权抢屏的 agent 状态。** 其余时间屏幕归你：板子怎么放、怎么拿，就显示哪一页。想见宠物就召唤它（摇一摇），板子从不替你猜。

- needs_you 能抢屏，因为屏上有事要你做：批准气泡。
- working 和 done 从不换页。它们只是氛围信息：脸页在屏上时自然看得到，done 还会出声。
- 两个意图冲突时，最近一次有意的操作获胜（见「最后意图获胜」）。

### 抢屏时发生什么

当前席位变成 needs_you 时：

1. 屏幕跳到该席位的脸页，按当前摆放或手持角度转正，浮出批准气泡。
2. 点一下 = 批准，长按 ≥ 0.7 s = 拒绝。
3. 答完后脸页再停 2 s，让你看清结果，然后回到原来那页。

非当前席位刚举手时，板子先切到那个席位，抢屏随之发生。按住语音键期间、睡觉期间不切。

### 另一种抢屏：认领卡

某台 Mac 请求成为板子的主人时，脸页弹出「连到这台 Mac？」卡片。只有绿色「连接」按钮算同意；点卡外、长按 ≥ 0.7 s、30 s 不点都算拒绝。卡片在时独占触屏。扣在桌上的板子不弹。

### 优先级

上面的行压过下面的行。扣桌睡觉在所有行之上：屏幕熄灭，下面都不生效。

| # | 来源 | 屏幕显示 |
|---|---|---|
| 1 | 认领卡 | 脸页 + 卡片 |
| 2 | 当前席位 needs_you，以及答完后 2 s | 脸页 |
| 3 | 手持中摇一摇（唤宠） | 脸页 |
| 4 | 钉住 | 钉住的页带 |
| 5 | 拿起时显示的绑定（仅手持中） | 绑定的页 |
| 6 | 摆放方向 | 朝下那条边对应的页 |

## 按摆放分页

边的叫法以屏幕正对你、三颗键在上为准。每条边上有什么见 [硬件](01-hardware.zh-CN.md)。

| 摆放 | 主页 | 左右滑 | 上下滑 |
|---|---|---|---|
| 竖放，三键朝上 | 脸页 | 切席位（左滑 = 右边那个席位进来） | 音量 ±10 |
| 左侧边（microSD 卡槽）朝下 | 钟表 | 左滑：Mac 正在播放；右滑：板上播客；不绕回 | 两个播放页上调音量 |
| 右侧边（喇叭）朝下 | 赛博黄历 | 任一方向：黄历 ⇄ 日历 | 黄历页：换一签 |
| 扣桌（屏幕朝下） | 睡觉 | — | — |
| 平躺（屏幕朝上） | 保持上一页 | — | — |
| 三键朝下 | 不算摆放，保持上一页 | — | — |

- 进入钟表页带落在钟表；如果板上播放器正在放，就直接落在播客页。
- 进入黄历页带落在黄历；板子切成英文时落在日历（黄历页保留中文）。
- 黄历每天五份签：往上 = 下一份，往下 = 上一份；绕回第一份时弹「命运自有回应」。点一下 = 宠物念出屏上那份签。
- 睡觉：屏幕熄灭、声音静音，板上播客暂停并记住位置。翻回屏幕朝上或拿起来即醒。

## 桌面上

| 事件 | 结果 |
|---|---|
| 换一条边立住 0.7 s | 那条边的主页 |
| 当前席位需要你 | 脸页，直到答完再加 2 s |
| 别的席位刚举手 | 板子切到那个席位，然后抢屏 |
| 你从等待中的席位滑走 | 该席位的抢屏结束 |
| 答完一个请求，还有别的席位在等 | 板子接力到那个席位 |
| 某个席位开始干活或干完 | 不换页 |
| 扣桌 0.8 s | 睡觉 |

## 手里

- **拿起**：一次晃动，且手指不在屏上。宠物露出惊讶脸，此后换面要稳 0.9 s 而不是 0.7 s。
- **确认持握**：晃动之后还持续运动至少 0.5 s。桌面上磕一下约 0.2 s 就平息，到不了这一步。拿起时显示的绑定和唤宠都只在确认持握后生效。
- **放下**：静止 1.5 s。回到当前摆放对应的页，唤宠结束。

| 你做什么 | 结果（拿起时显示 = `follow`） |
|---|---|
| 拿起来，别的不做 | 正对你的那页保持不变 |
| 转到另一面并稳住 0.9 s | 换成那一面的页 |
| 摇几下 | 唤宠：脸页（带眩晕表情；这段动画有 15 s 冷却） |
| 唤宠后转面并稳住 0.9 s | 离开脸页，换成那一面的页 |
| 在脸页上滑动 | 切席位 / 调音量，方向按你看到的画面算 |
| 当前席位需要你 | 脸页，按手持角度转正 |

抢屏、唤宠、钉住的页、绑定的页，在手里都按实时重力转正朝向你。

### 拿起时显示

手持期间显示哪一页。

| 取值 | 手持期间 |
|---|---|
| `follow`（默认） | 正对你的那页；换面会换页 |
| `face` | 始终是脸页 |
| `clock` | 始终是钟表 |
| `almanac` | 始终是黄历 |
| `smart` | `follow` 的旧名，行为相同 |

- 绑定的页随手持角度转正，换面不换页。唤宠和 needs_you 照样抢屏；钉住压过绑定。
- 在设置页「拿起时显示」里点选（点一下立即写进板子），或在 `~/.agentpet/config.json` 里写 `"pickup_page"`。板子把它存进 NVS，没有 host 也照常生效。

## 钉住

钉住 = 只听手、不听重力。钉住的页在板子翻面、拿起、手里转面时都不换，只按重力转正方便阅读。

| 项 | 行为 |
|---|---|
| 钉住 / 解除任意页 | 左键按住 1 s。到 1 s 即生效（手还没松），弹「钉住 / 解除钉住」1.5 s。短按仍是静音。 |
| 钉住 / 解除脸页 | 另一个入口：点脸页右下角（64 × 64 px），图钉没画出来时也有效。这一点不做别的事。 |
| 钉住的是什么 | 屏上正在显示的页带：脸页、钟表页带或黄历页带，并停在当时那一子页 |
| 页带内 | 滑动照常（钟表、播客、正在播放；黄历、日历；换签），钉住跟着走 |
| 图钉 | 右下角：先显示席位色 10 s，之后变灰常驻。未钉住时：桌面上不显示，手持中脸页上显示暗灰。其他页上的图钉不是按钮，解除用左键。 |
| 照常生效 | needs_you 照样抢屏，答完回到钉住的页；扣桌照样睡觉；手持中摇一摇照样短暂显示脸页 |
| 压过 | 摆放方向和拿起时显示的绑定 |
| 持久 | 存在 NVS，重启后仍钉住（灰色图钉） |

## 最后意图获胜

两个信号冲突时，最近一次有意的操作说了算。

| 冲突 | 胜者 |
|---|---|
| 摇出了脸页，随后转面并稳住 0.9 s | 转面：换成那一面的页 |
| 某席位需要你，你滑到别的席位 | 滑动：你离开的那个席位不再抢屏 |
| 板上滑动 vs. 在 Mac 上点进某个 agent 的 app | 后发生的那个 |
| 钉住 vs. 重力或拿起时显示 | 钉住 |
| 钉住 vs. needs_you | needs_you，答完回到钉住的页 |
| 按住语音键时来了新请求或 Mac 前台变了 | 语音键：席位不动，直到松手 |

板子和 Mac 互相跟随对方选的席位：

- **板子 → Mac**：最后一次滑动停手 1.5 s 后（`focus_settle_s`），Mac 把该席位的 app 拉到前台。连续快滑只拉最后一个。
- **Mac → 板子**：点进某个 agent 的 app 并在前台停 1 s，板子静默切到该席位。只认各家 agent 的 app。板上滑动后 5 s 内不跟、host 自己拉起 app 后 3 s 内不跟、按住语音键时不跟。`config.json` 里 `"follow_front": false` 可关闭。

## 判据参数

`motion` 是三轴加速度逐帧变化量之和的平滑值，单位 g。`gx`、`gy`、`gz` 是低通后的加速度，单位 g。参数在 `firmware/src/main.cpp` 的 `imuPoll` 和 `touchPoll` 里；滑动距离与每个摆放对应的页（`PAGES_BY_ORIENT`）在 `firmware/src/config.h`；最后两行跟随时间在 `host/agentpet_host.py`。

| 参数 | 值 |
|---|---|
| IMU 采样 | 25 Hz |
| 拿起晃动 | `motion` > 0.30，手指在屏上时不算 |
| 确认持握 | 晃动后 `motion` > 0.08 持续 0.5 s |
| 放下 | `motion` < 0.05 持续 1.5 s |
| 新摆放 | \|`gz`\| < 0.75 且 \|`gx`\| 或 \|`gy`\| > 0.45，稳定 0.7 s（拿起后 0.9 s） |
| 扣桌 → 睡觉 | `gz` < −0.75 持续 0.8 s |
| 唤醒 | `gz` > 0.5，或 `motion` > 0.08 持续 0.5 s |
| 摇晃 | 3 次 > 0.70 的冲击，彼此间隔 ≥ 150 ms，1.2 s 内 |
| 眩晕动画冷却 | 15 s（只管动画，不管页面） |
| needs_you 答完停留 | 2 s |
| 批准 / 拒绝 | 点 / 长按 ≥ 0.7 s；两次决定至少隔 1 s |
| 切席位滑动 | 80 px，直线度 2:1，300 ms 后裁决（区分摸头） |
| 音量滑动 | 60 px，直线度 1.5:1，立即执行 |
| 钉住 | 左键 1 s；名牌 1.5 s；席位色 10 s；角落 64 × 64 px |
| 认领卡 | 30 s 内作答 |
| Mac → 板子跟随 | app 在前台 1 s；板上滑动后等 5 s，host 自己拉起后等 3 s |
| 板子 → Mac 跟随 | 最后一次滑动后 1.5 s（`focus_settle_s`） |

## 取舍与边界

- 三键朝下永远不算摆放：桌面上保持上一页。手里只有抢屏、唤宠、钉住的页和绑定的页会转到这个角度朝向你。
- 平躺时没有哪条边朝下，所以保持上一页。
- 睡觉压过一切。needs_you 不会点亮扣着的板子，按键和点屏也不唤醒，这是有意的。翻过来或拿起来即可。
- 一次只答一张卡：抢屏只跟当前席位。第二个在等的席位，等第一个答完再轮到。
- 请求在屏上时和 Mac 断了链，脸页保持（板子只能相信最后收到的状态），点了也不会发出去。链路恢复即自愈。
- 右键按下即开始听写，从不等待区分短按和长按，所以它不带第二种功能。
- 设置卡（长按脸 1.5 s）的按钮按三键朝上的脸页判定点击。画面转过角度时可能点不准，先把板子竖起来。
